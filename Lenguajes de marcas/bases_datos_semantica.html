Concepto y Tipos de Bases de Datos

Bases de Datos Relacionales (RDBMS)

Las Bases de Datos Relacionales organizan la información en tablas compuestas por filas (registros) y columnas (campos), lo que permite relacionar y consultar datos mediante el lenguaje SQL.

Ejemplos populares de Sistemas Gestores de Bases de Datos (SGBD) relacionales incluyen:

  • MySQL
  • PostgreSQL
  • Oracle

Bases de Datos No Relacionales (NoSQL)

Las Bases de Datos NoSQL están diseñadas para gestionar grandes volúmenes de datos no estructurados o semiestructurados, ofreciendo alta escalabilidad y flexibilidad. A diferencia de las relacionales, no requieren un esquema rígido.

Existen varios tipos de almacenamiento según el modelo de datos:

  • Orientado a documentos
  • Clave-valor
  • Grafos
  • Columnares

Ejemplos populares de bases de datos NoSQL:

  • MongoDB
  • Redis
  • Cassandra
  • Neo4j

Estructura de una Base de Datos Relacional

Componentes Fundamentales

Para definir la estructura dentro de un modelo relacional se emplean los siguientes elementos:

  • Tablas (Entidades): Estructuras donde se organizan los datos.
  • Campos (Atributos): Columnas que definen la tipología de información.
  • Registros (Tuplas): Filas que contienen cada instancia concreta de datos.
  • Claves primarias (Primary Key): Identificadores únicos de cada registro.

Cardinalidades y Claves Foráneas

Cardinalidades Fundamentales:

  • Relación 1:1 (Uno a uno): Un registro de la tabla A se conecta con un solo registro de la Tabla B y viceversa.
  • Relación 1:N (Uno a muchos): Un registro de la Tabla A se relaciona con varios registros de la Tabla B, pero cada registro de la Tabla B solo pertenece a un único registro de la Tabla A.
  • Relación M:N (Muchos a muchos): Un registro de la Tabla A se relaciona con varios registros de la Tabla B, y a la vez, un registro de la Tabla B se relaciona con varios registros de la Tabla A, requiriendo una tabla intermedia.

Clave Foránea (Foreign Key)

Para llevar a cabo estas relaciones, se emplea una Clave Foránea (Foreign Key), que es un campo o conjunto de campos en una tabla que hace referencia a la clave primaria (Primary Key) de otra tabla garantizando la integridad referencial de los datos.

Glosario de Términos

• SQL (Structured Query Language)
- Lenguaje estándar y declarativo para realizar consultas a una base de datos, donde se indica qué datos se quieren obtener y no cómo conseguirlos.
• SGBD (Sistema Gestor de Base de Datos)
- Software diseñado para almacenar, gestionar, recuperar y proteger datos de manera eficiente, proporcionando herramientas para definir, manipular y controlar el acceso a los datos, garantizando su integridad y seguridad.
• Normalización
- Proceso de diseño de bases de datos que organiza los datos en estructuras de tablas específicas para ayudar a mejorar la integridad de los datos, prevenir anomalías de datos, minimizar la redundancia de datos y reforzarel rendimiento de las consultas.
